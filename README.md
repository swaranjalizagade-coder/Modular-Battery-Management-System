Modular Battery Management System

Project Overview

This project implements a Modular Battery Management System (BMS) using Wokwi simulation.

Main Features

- Battery cell voltage monitoring.
- Weakest and strongest cell identification.
- Voltage imbalance detection.
- Non-blocking protection relay and safety system.
- Fault detection and state management.
- LCD display management.
- Event-driven telemetry.
- Blynk dashboard monitoring and analytics.

Project Files

- "sketch.ino" – Main project source code.
- "diagram.json" – Circuit configuration.
- "libraries.txt" – Required libraries.
- "wokwi-project.txt" – Wokwi project configuration.
